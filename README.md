# Banking Management Portal API

A secure RESTful Banking Management Portal built with **Spring Boot** and **Spring Security**. The API enables user authentication, account management, fund transfers, transaction history, PIN management, and secure banking operations.

## Features
- User Registration & Authentication (JWT)
- Account Management
- Cash Deposit & Withdrawal
- Fund Transfer
- Transaction History
- PIN Management
- Global Exception Handling

## Tech Stack
- Java
- Spring Boot
- Spring Security
- MySQL
- Maven
- JWT Authentication
- REST APIs


## Future Enhancements
